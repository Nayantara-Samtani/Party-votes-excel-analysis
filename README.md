# Party-votes-excel-analysis

Excel data analysis project demonstrating Pivot Tables, filtering, aggregation, and reporting on Canadian parliamentary data.
This is one of my early Excel data analysis projects where I explored a dataset containing information on Canadian Members of Parliament (MPs). Using Excel, I analyzed political party representation across Canada and within specific provinces to better understand regional trends and patterns in parliamentary data.

I organized and explored the dataset using Microsoft Excel, creating Pivot Tables to summarize political party representation and filtering data by province to compare regional differences. Through this project, I developed hands-on experience with Pivot Tables, data filtering, data aggregation, and reporting techniques used to turn raw data into meaningful summaries. Overall this analysis highlighted how political party representation varies across Canada and within Ontario and by summarizing the dataset through Pivot Tables, I was able to quickly identify patterns in party distribution and demonstrate how Excel can be used to analyze and report on such large datasets.
